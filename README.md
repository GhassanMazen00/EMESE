# EMESE — موقع الشركة

موقع عرض لـ **EMESE**، شركة توريدات مخصّصة في مصر (يونيفورمات مطبوعة ومتطرّزة، كشاكيل، أقلام، أعلام، كروت، مجات وهدايا شركات).
الموقع كله بالعامية المصرية ومن اليمين للشمال.

## الأقسام
- **الرئيسية**: تعريف سريع بتصميم مستوحى من ألوان الطباعة (CMYK).
- **بنعمل إيه**: كروت للمنتجات وطرق الطباعة المناسبة لكل منتج.
- **الاستوديو 3D**: معاينة حيّة بـ three.js لـ ٦ منتجات (تيشيرت، كشكول، قلم، مج، علم، كارت).
  العميل يكتب اسمه، يختار طريقة الطباعة (DTF، تطريز، سبلميشن، UV DTF، UV، ليزر) ولون المنتج والحبر،
  وبيقدر ينزّل الموكب صورة PNG أو يطلبه على طول.
- **المكن**: شرح كل مكنة بالبلدي.
- **خطوة بخطوة**: من الفكرة لحد التوصيل، بأنيميشن مع السكرول.
- **كلّمنا**: فورم بيفتح رسالة واتساب جاهزة.

## التشغيل
موقع static، مفيش build. أي سيرفر بسيط ينفع:

```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```

(لازم يتفتح من سيرفر مش من الملف مباشرة، عشان الـ ES modules.)

ينفع يترفع على GitHub Pages أو Netlify أو Vercel كما هو.

## قبل النشر
- غيّر رقم الواتساب في `js/main.js` (`WHATSAPP_NUMBER`) — الرقم الحالي placeholder.
- three.js موجودة في `js/vendor` (نسخة 0.160.0، رخصة MIT) فالموقع مش معتمد على CDN.

## الملفات
```
index.html        الصفحة
css/style.css     التصميم
js/main.js        السكرول، الخطوات، فورم الواتساب
js/studio.js      الاستوديو الـ3D
js/vendor/        three.js
assets/           الأيقونة
```
