# EMESE | موقع الشركة

موقع عرض لـ **EMESE**، شركة توريدات مخصّصة في مصر (يونيفورمات مطبوعة ومتطرّزة، كشاكيل، أقلام، أعلام، كروت، مجات، شنط وهدايا شركات).
الموقع عربي (عامية مصرية) وإنجليزي، والعربي والوضع الفاتح هما الافتراضي أول ما حد يفتح الموقع.

## الأقسام
- **الرئيسية**: الشعار بيتطبع قدامك بألوان الحبر الثلاثة (سيان وماجنتا وأصفر) وبعدين يتظبط على الأسود، زي ما المطبعة بتظبط الألوان.
  جنبه كارت بيعرض منتجات حقيقية عليها لوجو EMESE، بيتبدّلوا لوحدهم وتقدر تسحبهم بصباعك أو بالماوس.
- **«جرّب اللوجو بتاعك على كل المنتجات»**: الزائر يرفع اللوجو مرة واحدة، وكل منتج في الصفحة (الكارت اللي فوق وكروت المنتجات) بيتعاد رسمه باللوجو بتاعه، بنفس الطريقة اللي اتنفّذ بيها (تطريز، ليزر، فويل…).
  اللوجو بيفضل على جهازه، ونفس اللوجو بيظهر في الاستوديو وفي فورم الطلب.
- **بنعمل إيه**: كروت بصور منتجات حقيقية، وتحتها **القايمة الكاملة** (حوالي ١٠٠ منتج في ٩ مجموعات، منها مجموعة كاملة للكابات والبرانيط). القايمة مقفولة لحد ما الزائر يدوس «استكشف القايمة كلها» أو اسم مجموعة، وجوّاها فلتر حسب طريقة التنفيذ:
  ليزر، DTF، UV، UV DTF، سبلميشن، سلك سكرين، تطريز، تصنيع ملابس، نسيج، سوست. الداتا في `js/everything.js` وسهل تزوّد عليها.
- **الاستوديو** (مقفول لحد ما الزائر يدوس «افتح الاستوديو»، فالصفحة بتفتح أسرع): ١٩ منتج متقسّمين ملابس / إكسسوارات / مكتب وهدايا. العميل يرفع اللوجو بتاعه (أو يكتب نص)، يختار المنتج وطريقة التنفيذ (DTF، سلك سكرين، تطريز، سبلميشن، UV، UV DTF، ليزر، فويل) ولون المنتج،
  ويحرّك التصميم بالسحب ويكبّره ويصغّره ويلفّه. وبعدين ينزّل الموكب صورة أو يطلبه.
- **خطوة بخطوة** و**المكن**.
- **اطلب عرض سعر**: المنتج والطريقة واللون والكمية والميعاد، واللوجو والموكب من الاستوديو بيتضافوا لوحدهم.
  لو قاعدة البيانات متوصّلة، الطلب بيتحفظ والعميل بياخد رقم طلب ولينك يتابع منه. ولو مش متوصّلة، بيتفتحله رسالة واتساب جاهزة.
  وممكن يظهر سعر تقريبي لو ملّيت الأسعار في `js/pricing.js`.

## صفحات الطلبات
- `track.html?o=…` **متابعة الطلب**: العميل بيشوف مرحلة الطلب، والسعر، والتصميمات، ويوافق على التصميم أو يطلب تعديل، من غير ما يعمل حساب.
- `sizes.html?l=…` **تجميع المقاسات**: لينك بتبعته الشركة للموظفين، وكل واحد يكتب اسمه ومقاسه.
  و`sizes.html?a=…` لينك تاني للمسؤول في الشركة يشوف القايمة كاملة والإجمالي لكل مقاس وينزّلها شيت.
- `admin.html` **لوحة الفريق**: الطلبات كلها، تغيير الحالة، السعر، رفع التصميمات للموافقة، ولينكات واتساب جاهزة، وقوايم المقاسات.
- `bulk.html` **أسماء بالجملة**: قايمة أسماء (أو شيت CSV)، والنتيجة ملف ZIP فيه موكب لكل اسم وملف طباعة شفاف للمكنة. شغالة من غير قاعدة بيانات.
- الموقع كمان بيتسطّب على الموبايل زي التطبيق (أيقونة على الشاشة الرئيسية) وبيفتح من غير نت.

## توصيل الطلبات (Supabase، مجاني للبداية)
1. اعمل مشروع على [supabase.com](https://supabase.com) (منطقة Frankfurt أقرب لمصر).
2. افتح SQL Editor وشغّل محتوى `supabase/migrations/20261102000000_orders.sql` كله.
3. من Project settings، API: انسخ Project URL ومفتاح anon public وحطّهم في `js/config.js`.
4. حسابات الفريق: من Authentication، Users اعمل يوزر لكل حد في الفريق، وبعدين في SQL Editor:
   `insert into public.staff (user_id, name) select id, 'الاسم' from auth.users where email = 'team@example.com';`
5. افتح `admin.html` وادخل.

الأمان: الزوّار مش بيقروا أو يعدّلوا الجداول خالص. كل حاجة بتعدّي على functions بتاخد لينك سرّي (token) لكل طلب أو قايمة،
والفريق بس (اللي في جدول staff) يشوف ويعدّل كل حاجة. الصور اللي بيرفعها الزوّار ليها مكان محدّد ومش بيقدروا يعدّلوا أو يمسحوا حاجة.

## التشغيل
موقع static، مفيش build:

```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```

ينفع يترفع على GitHub Pages أو Netlify أو Vercel كما هو.

## قبل النشر
- **اللوجو**: حط لوجو الشركة الحقيقي مكان `assets/logo.png` (PNG بخلفية شفافة، عرض حوالي ١٠٠٠ بكسل أو أكتر).
  الاستوديو هيستخدمه على طول. وبعدها شغّل `python tools/mockups/cards.py` عشان صور الكروت وكارت الرئيسية يتعملوا باللوجو الجديد
  (محتاج `pip install numpy pillow` بس، من غير Blender).
- **الواتساب**: غيّر `WHATSAPP_NUMBER` في `js/config.js` (الرقم الحالي placeholder).
- **الأسعار** (اختياري): املا `js/pricing.js` عشان يظهر سعر تقريبي في فورم الطلب.

## الموكبات الواقعية (إزاي اتعملت)
كل منتج في `assets/mockups/<id>/` متصوّر بـ Blender (رندر Cycles) من السكريبتات اللي في `tools/mockups/`.
مع الصورة بنطلّع كام صورة بيانات: الإضاءة اللي واقعة على المنتج، لونه الأصلي، اللمعة، ومكان كل نقطة من مساحة الطباعة.
المتصفح (`js/mockup.js`) بيستخدمهم عشان يحط أي لوجو على الصورة ويلفّه مع الكسرات والانحناءات، ويغيّر لون المنتج من غير ما الإضاءة تبوظ.

لإعادة الرندر (محتاج Blender كـ Python module):

```bash
pip install bpy numpy pillow
python tools/mockups/render.py                 # كل المنتجات
python tools/mockups/render.py tee mug         # منتجات معيّنة
python tools/mockups/render.py tee --preview   # صورة سريعة للتجربة
```

## إضافة منتج من صورة حقيقية
أحسن نتيجة بتيجي من صورة حقيقية أو موكب جاهز للمنتج **من غير لوجو**، ويفضّل يكون لونه أبيض أو فاتح:
1. حط الصورة في `tools/mockups/photos/<id>/photo.jpg`، واعمل القصّ بتاعها `alpha.png` (مثلًا بـ `rembg`).
   الصورة الأصلية مش بتترفع على GitHub (الريبو عام، وصور Canva وأمثالها مينفعش تتشارك كملف لوحدها)، فخلّي نسخة منها عندك.
2. زوّد المنتج في `PHOTOS` جوّه `tools/mockups/from_photo.py` (مكان الطباعة، وأي حاجة فوقها زي الأحبال).
3. شغّل `python tools/mockups/from_photo.py <id>` وبعده `python tools/mockups/cards.py`.

لو الصورة صغيرة، كبّرها الأول: `python tools/mockups/upscale.py in.png out.png --scale 2`.

التصميمات اللي بتتعمل لعميل معيّن (زي `assets/designs/emese-streetwear.png`) بتتحدّد في `cards.py`.
